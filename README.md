# Ian's App 📱

A cross-platform mobile application built with React Native and Expo. This project uses GitHub Actions to automatically compile and build Android `.apk` binaries on every code push.

---

## 🚀 Features

* **Home Dashboard:** Clean UI layout with personal greeting and status metrics.
* **Automated CI/CD:** Builds an Android APK automatically using GitHub Actions.
* **Cross-Platform Foundation:** Powered by React Native and Expo.

---

## 📥 How to Download & Install

1. Go to the **Actions** tab in this GitHub repository.
2. Select the latest successful workflow run (**Build Android APK**).
3. Scroll down to the **Artifacts** section at the bottom.
4. Download the `app-debug` file, extract the `.zip`, and install `app-debug.apk` on your Android device.
